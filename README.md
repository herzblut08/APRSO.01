# Информационная система автоматизации процессов работы студенческого общежития (АПРСО)

## Описание проекта
Данный проект разработан в рамках учебной практики УП.02.01
Система предназначена для автоматизации административных и хозяйственных 
процессов студенческого общежития.

## Структура репозитория

| Ветка | Содержимое |
|-------|-----------|
| `case_task_1` | Моделирование бизнес-процессов ИС (IDEF0, IDEF3, DFD, UML-диаграммы) |
| `case_task_2` | Архитектурное проектирование ИС (прототипы, ТЗ, архитектурная модель) |
| `case_task_3` | Графический интерфейс C++ (исходный код Windows Forms) |
| `case_task_4` | Организация хранения проекта (документация по GitHub) |

## Используемые технологии
- C++/CLI, Windows Forms (.NET Framework 4.7.2)
- Visual Studio 2022
- Draw.io (диаграммы)
- Figma (прототипы интерфейса)
- Kaiten (планирование)
- GitHub (хранение проекта)
