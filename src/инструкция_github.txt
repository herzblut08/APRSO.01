Инструкция по работе с репозиторием:

1. Клонирование репозитория:
   git clone https://github.com/[herzblut08]/APRSO.01.git

2. Переключение на ветку:
   git checkout case_task_1

3. Просмотр всех веток:
   git branch -a

Система контроля версий Git обеспечивает:
- Историю изменений
- Резервное копирование
- Командную работу
